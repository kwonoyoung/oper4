# 교육공무원 호봉획정 (oper4)

`index.html`의 기존 화면에 호봉 계산과 승급기록을 연결한 정적 웹 앱입니다.
입력자료는 해당 브라우저에 저장되며 계산 중 외부로 전송하지 않습니다.

## 비교 기준

- 비교 기준: 공개된 교육공무원 호봉획정 프로그램의 계산 결과(2026-09-16 확인)
- 비교 범위: 산입 기간, 행별 환산, 임용 전 합계, 임용 후 합계 및 보정일,
  학령·가산연수·특수학교 가산, 사정호봉, 잔여월일, 차기승급일, 승급기록,
  자녀별 육아휴직 12/18개월, 1정 자격 취득, 계약제 상한,
  석사·박사 경력 상한, 시간강사 4가지 계산 방식.
- 기준 예제: 임용 전 3년 7월 7일, 임용 후 12년 0월 25일, 보정 -1일,
  합계 15년 8월 2일, 25호봉, 차기승급일 2021-07-01, 승급 후 잔여 2일.
- 특정 프로그램 전체를 복제한 사이트가 아닙니다. 비교 대상 버전의 결과를
  목표로 구현했으며, 향후 변경사항을 자동으로 동기화하지 않습니다.
- 법령의 모든 예외를 검증했다는 의미는 아닙니다. 경력 인정·적용률·퇴직일
  산입·징계·승급제한은 담당자가 증빙 및 적용 규정에 따라 확인합니다.

## 입력과 계산

1. 임용 전 종료일은 **산입하는 마지막 날**입니다. 퇴직일 제외 대상이면 전날을 입력합니다.
2. 임용 후 첫 행은 임용일에 고정됩니다. 다음 행의 시작일 전날 및 최종 기준일
   전날을 종료일로 사용합니다. 행을 날짜 순서대로 입력합니다.
3. 실제 365/366일을 360일로 나누지 않습니다. 달력 기간을 먼저 계산한 뒤
   `연×360 + 월×30 + 일`에 환산율을 적용하고 소수 일수를 버립니다.
4. 기준 사이트처럼 임용 전 경력은 행별 합산하고, 임용 후 연속된 100% 산입
   경력을 묶어 계산합니다. 보정일은 합친 값과 행별 합계의 차이입니다.
5. 첫째·둘째 육아휴직은 자녀별 상한을 누적 적용합니다. 셋째 이상은 100%로
   입력됩니다. 휴직 종류와 상한 선택은 해당자의 적용 기준에 맞춰 확인합니다.
6. 일반→초임 또는 계약제 옵션 변경 시 기준 사이트와 같이 첫 임용 후 행은
   0%로 변경됩니다. 계약제 결과는 차기승급일을 표시하지 않습니다.
7. 기존 초안의 학령/가산 월 입력은 기준 사이트에 대응하지 않습니다.
   저장된 월 값이 있으면 경고하고 결과 확정을 막아 연 단위 입력을 확인합니다.

## 저장·이전

- 새 저장 키: `edu_public_officer_hobong_v2`.
- 기존 `edu_public_officer_hobong_draft_v1` 자료가 있으면 불러옵니다.
  원본 키는 마이그레이션으로 삭제하지 않습니다. 임용일로 구분을 추정했으므로
  표시되는 안내에 따라 임용 전/후, 휴직 종류와 산입 마지막 날을 확인합니다.
- JSON은 재입력 가능한 백업입니다.
- XLSX는 별지 제17호 호봉획정표 표준 서식 **4개 시트**(호봉획정표·자료·계산·승급기록)로
  저장합니다. 호봉획정표·계산 시트는 수식이 살아 있어 엑셀에서 노란색 셀을 고치면 자동
  재계산되고, 승급기록 시트는 앱에서 계산한 값입니다. 엑셀 **가져오기** 기능은 구현
  범위가 아닙니다.

비교 대상과 달력 기간 6,000건, 혼합 경력 360건, 공개 예제 1건,

구성: `hobong-engine.js` 순수 계산, `app.js` 입력/표시/이전,
`xlsx-export.js` 표준 서식의 수식 포함 OOXML 내보내기.
